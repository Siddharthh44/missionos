# Anti Patterns

## Product Anti-Patterns

Do NOT build:

* a traditional HRMS portal
* a boring CRUD dashboard
* a spreadsheet replacement UI
* enterprise-heavy workflows
* multi-level nested navigation
* forms with excessive fields
* giant table-first pages
* popup-heavy interfaces

Avoid:

* “Submit / Approve / Reject” appearing everywhere
* dense KPI blocks
* outdated admin panel aesthetics
* excessive dropdown menus
* overly technical wording
* robotic UX copy

---

# Design Anti-Patterns

Avoid:

* Bootstrap-style layouts
* sharp-edged enterprise cards
* too many colors
* excessive gradients
* inconsistent spacing
* tiny text
* cluttered analytics
* overly bright UI

Do NOT:

* copy Linear directly
* clone Notion directly
* mimic Jira
* imitate SAP-style software

Take inspiration only from:

* clean productivity software patterns
* modern SaaS dashboards
* lightweight collaboration tools

---

# UX Anti-Patterns

Avoid:

* forcing users through long flows
* unnecessary confirmation modals
* hidden critical actions
* overwhelming dashboards
* walls of text
* excessive tabs
* deep settings pages

Prioritize:

* fast actions
* clarity
* visible progress
* momentum
* contextual actions

---

# Engineering Anti-Patterns

Do NOT:

* over-engineer architecture
* use microservices
* create unnecessary abstractions
* optimize prematurely
* create deeply nested folders
* build custom state systems unnecessarily

Avoid:

* giant monolithic components
* duplicated logic
* overcomplicated hooks
* magic constants
* excessive prop drilling

---

# Hackathon Anti-Patterns

Never spend excessive time on:

* perfect backend architecture
* enterprise-grade auth
* unnecessary integrations
* overcomplicated RBAC
* advanced caching systems
* edge-case perfection

If something is:

* low visual impact
* low demo value
* high implementation cost

SKIP IT.

---

# Demo Anti-Patterns

Avoid demos that:

* start with login screens
* open boring tables first
* require long explanations
* hide the “wow” features
* feel like admin software

The first 45 seconds must:

* look premium
* show motion
* show progress
* show analytics
* feel interactive
* communicate value instantly
